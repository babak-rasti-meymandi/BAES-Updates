# News and Updates

![Progress and development](../assets/images/04-progress-development.svg)

This directory contains dated, public-facing updates about BAES-related activity.

## What belongs here

- project announcements and meaningful milestones;
- public research or evaluation updates;
- submissions or applications, when disclosure is appropriate;
- publication and release announcements;
- concise status changes that are useful to external readers.

## Editorial rules

- Use dates in filenames where practical: `YYYY-MM-DD-short-description.md`.
- State whether an item is **planned**, **in progress**, **submitted**, **published**, or **completed**.
- Do not describe a submitted proposal as funded or accepted unless that outcome has been confirmed.
- Link to public artifacts when available.
- Do not publish confidential correspondence or private information without permission.

Updates should record verifiable activity, not serve as promotional claims unsupported by evidence.
